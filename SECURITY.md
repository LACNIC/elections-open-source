# Security Policy

## Reporting a vulnerability

Si detectas una vulnerabilidad de seguridad, no la publiques en un issue abierto.
Repórtala por el canal privado definido por la organización responsable de este proyecto.

## Scope

Esta política cubre:

- credenciales y secretos expuestos
- configuraciones inseguras
- dependencias con riesgos conocidos
- problemas de acceso o autenticación

## Good practice

- Rota secretos si alguno llegara a quedar expuesto.
- Evita subir `.env`, claves privadas, dumps o logs.
- Mantén ejemplos y documentación sin valores reales.
