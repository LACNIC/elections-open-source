{{ "Instalación, configuración y actualización del Sistema de Elecciones" }}

El Sistema de Elecciones es una iniciativa open source pensada para que cualquier organización pueda adaptarla a su propio contexto. Está desarrollado en Java usando el framework Wicket de Apache, corre sobre WildFly como servidor de aplicaciones y usa PostgreSQL como motor de base de datos. La instanciación vigente del sistema se realiza con Docker.

No es necesario disponer de servicios de LACNIC para operar una instancia. La configuración base para una organización independiente usa autenticación local APP, gestión manual de organizaciones y padrón, Campus deshabilitado y asistencia de IA opcional. Los nombres técnicos históricos que incluyen LACNIC o MILACNIC se mantienen por compatibilidad, no porque la instalación dependa de esa organización.


{{ "Instalación y configuración" }}

Para instalar y configurar el sistema, use la guía de instanciación con Docker. El perfil fresh permite evaluar o iniciar una instancia autocontenida; una instalación productiva debe usar servicios, secretos, correo, backups, monitoreo y TLS administrados por la organización. La instalación manual de WildFly queda como alternativa avanzada.

  • Instanciación con Docker: siga esta guía para preparar base de datos, crear el primer administrador local, configurar variables de ambiente, construir la imagen y desplegar.

{{ "Actualización" }}

Cuando se libera una nueva versión del Sistema de Elecciones (ver Release notes), puede actualizarlo siguiendo esta guía.


{{ "Gestion funcional" }}

Para relevar y operar una eleccion ya creada, use la guia funcional de alta y configuracion base junto con las guias especificas de los modulos posteriores.

  • Elecciones: gestione la creacion, el detalle base, los presets por tipo y la configuracion operativa desde esta guia.
  • Organizaciones: cargue, sincronice y mantenga organizaciones desde esta guia.
  • Padron: cargue, sincronice y mantenga votantes desde esta guia.
  • Calendario y tareas: configure etapas, hitos publicables, dependencias y orden de tareas desde esta guia.
  • Candidaturas y nominaciones: opere altas manuales, nominaciones, apoyos y publicacion de candidatos desde esta guia.
  • Preguntas, declaraciones y comunidad: documente el bloque de preguntas estatutarias/no estatutarias, declaraciones obligatorias y preguntas de comunidad desde esta guia.
  • Auditoria previa y final: gestione auditores, decisiones por candidato, conformidad final y revision de votos desde esta guia.
  • Votacion y links publicos: releve rutas tokenizadas, recovery, nominacion, apoyo, votacion y resultados publicos desde esta guia.
  • Resultados y reportes: revise dashboard interno, pre-reportes, resultados publicos y auditoria final desde esta guia.
  • Parametros, templates e i18n: administre configuracion global, personalizacion visual, templates base/por eleccion y reglas reales de idioma desde esta guia.
  • Seguridad y accesos: configure login local sin PAI o autenticacion externa, roles, CAPTCHA, rate limits, tokens y autenticacion WS desde esta guia.
