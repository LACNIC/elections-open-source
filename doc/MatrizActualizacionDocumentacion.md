# Matriz de actualización de documentación 3.0

## Objetivo

Actualizar la documentación existente del sistema para que describa fielmente el funcionamiento actual de `v3.0`, tomando como línea base histórica `v2.3` y evitando completar release notes o guías con supuestos no verificados.

Esta matriz sirve para controlar qué documentos ya fueron revisados, qué falta contrastar contra el código y qué documentos nuevos conviene crear.

## Estado vigente de la distribución snapshot — 2026-09-08

- Rama de distribución: `develop-v3-snapshot` del repositorio `LACNIC/elections-open-source`.
- La instalación para terceros se documenta en [README](../README.md), [Docker](../dockers/DOCKER.md) y [manual de instalación](manual.html). Cada organización debe crear su `.env` desde el ejemplo y configurar sus propios valores.
- El commit `f982533` restauró archivos de compilación y despliegue omitidos en la importación, ajustó el arranque Docker y alineó los enlaces al repositorio de distribución. Se verificaron compilación completa, inicialización de una base vacía, login y acceso HTTP a la documentación incluida.
- Se retira el borrador Markdown de configuración inicial; no queda pendiente completarlo ni agregarle capturas. Las referencias vigentes son las guías de [seguridad](security-access.html) y [parámetros y personalización](parameters-templates-i18n.html), además de las guías de instalación.
- Se retira también la nota de convenciones de visibilidad de los ejemplos HTML, que contenía rutas personales del equipo de desarrollo.
- Se retira también el PDF base v3.0 de configuración inicial, que era un documento de trabajo sin capturas. Las guías HTML vigentes sustituyen al borrador y a este PDF. Esta limpieza no elimina archivos ni autorías del historial Git.

El registro fechado que sigue conserva decisiones y verificaciones de su momento. Sus estados antiguos no reemplazan este resumen ni implican que se hayan repetido todas las pruebas en esta actualización documental.

## Criterios de estado

| Estado | Significado |
| --- | --- |
| Pendiente | Todavía no fue revisado contra el sistema actual. |
| En relevamiento | Se está comparando el documento contra código, configuración, scripts o flujos reales. |
| En redacción | Ya se identificó el contenido vigente y se está actualizando el documento. |
| En revisión | El documento fue actualizado y falta validación final de links, build o revisión funcional. |
| Actualizado | El documento quedó alineado al sistema actual y validado. |
| No vigente | El documento o sección ya no representa un flujo soportado y debe archivarse, eliminarse o marcarse como legado. |
