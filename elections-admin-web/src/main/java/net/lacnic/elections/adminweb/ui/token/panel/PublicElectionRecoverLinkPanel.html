Este panel permite recuperar los enlaces de participación asociados a esta elección: el enlace de votación para emitir el voto, el enlace de nominación para postular candidatos y el enlace de apoyo para confirmar apoyos solicitados.

Al ingresar una dirección de correo electrónico, el sistema busca coincidencias del correo con los distintos tipos de participación, de encontrarlas, envía un correo por cada enlace encontrado (hasta 10 enlaces).

Si usted es asociado de LACNIC y tiene acceso a MiLACNIC, puede encontrar sus enlaces de participación en esa plataforma. En estos casos, no se envían enlaces de participación desde este formulario
